# Math Blast · MB-W01-L1 · веб-эквивалент книги

**Тема:** Что такое математическое доказательство? Истинность утверждений.  
**План:** модуль 1, неделя 1, занятие 1 из 144.  
**Статус:** **PREVIEW** (PDF-кандидат пока `DRAFT`; выпуск требует независимого ревью по `02_REVIEW_MANUAL.md`).

## Открыть

Из распакованного архива откройте `OPEN_WEB_BOOK.html` или `books/MB-W01-L1/index.html` в браузере. Книга автономна: локальный MathJax, структурированный материал внутри HTML, SVG и PDF. Для развёртывания на GitHub Pages скопируйте `books/` и `materials/` в корень Math Blast. Исходную главную страницу `index.html` сохраните; интеграцию ссылки на урок №1 производите минимальным патчем (в PR сделана отдельно).

## Содержание

- 13 теоретических разделов и 13 иллюстраций SVG по TikZ;
- 39 мини-упражнений с короткими ответами;
- 30 полностью разобранных примеров;
- 9 алгоритмических схем SVG и 9 блоков по 10 задач;
- 90 упражнений уровней A30/B30/C20/D10, две подсказки на каждое, 90 полных решений;
- таблица из 90 ответов, 11 методических эвристик, 59 дополнительных вопросов с ответами;
- библиография, локальное сохранение статусов/заметок, светлая/тёмная тема, печать.

## Сборка

```bash
python build_web.py
```

Генератор берёт **точно** `books/MB-W01-L1/content.json`. Этот файл соответствует исходному `content/book.json` архивного пособия и сохраняет все ID. Отдельная редакция задач для веба отсутствует. Шаблон `book_shell.html` + инлайн-канонический JSON позволяют открывать книгу локально, даже без HTTP-сервера. Локальный MathJax расположен в `vendor/` и не обращается к CDN.

## Проверки

```bash
python qa/test_web.py
```

Результат данной сборки: **55/55 PASS** по структурному паритету, PDF ID, основным сценариям, математическому рендерингу и viewport 320/375/768/1024/1440 px. В ограниченной среде браузер блокировал `file://` и localhost-навигацию: тесты функциональности запускались с инъекцией локальных HTML/CSS/JS и имитацией localStorage. Системные end-to-end тесты настоящего URL, полноценная автоматическая проверка печати и доступности axe-core остаются **NOT_RUN**. Сам PDF 121 A4 страниц предоставлен внутри архива.

**Отдельное состояние:** `mathblast_book_progress_v1:MB-W01-L1`; исходный ключ `olympiad_math_plan_v2` остаётся без изменений. Никаких автоматических оценок свободных доказательств и передачи ответов третьим лицам нет.

## Важные ограничения

- Статус `PREVIEW` относится к редакционному процессу; интерфейс ученика не содержит служебных SHA и отметок.
- При печати из браузера раскрывается полное содержимое. При необходимости полиграфически точной A4-версии используйте связанный оригинальный PDF.
- Проверка семантического равенства всех 121 страниц и всех математических деталей SVG требует независимого этапа `04_REVIEW_WEB.md` и утверждения PDF-источника.
