## Открытые выпускные условия

1. **BLOCKER: публичный сайт отсутствует.** GitHub API сообщает `has_pages=false` для репозитория. Администратор должен выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**. Коннектор не обладает действием включения Pages.
2. После включения и приёмки PR #2 выполнится заготовленный workflow `.github/workflows/pages.yml`, который публикует статический сайт и запускает `qa/e2e_pages.py` **по настоящему публичному HTTPS URL**. Пока этот шаг `NOT_RUN`.
3. Для финального `APPROVED` по W6 необходим ручной контроль со скринридером и масштабом 400% либо документированное исключение; axe 0 violations — только автоматическая часть.
4. Остальные PARTIAL из W5/W7/W8 должны быть закрыты повторным содержательным/безопасностным/производительным аудитом опубликованной версии. До этого PR #2 остаётся Draft.

**Вердикт:** качественная веб-книга с полностью подтверждённой структурной полнотой и работающими HTTP-скриптами. **PREVIEW / BLOCKED FOR PUBLIC APPROVAL** до активации Pages, HTTPS E2E и заключительного выпуска. PDF-источник утверждён и опубликован в `main`.
