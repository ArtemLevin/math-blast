## Методический стандарт v2 (предложение)
1. Условие: контекст, объекты, исходное состояние, система отсчёта при необходимости, допущения, однозначный вопрос. Без подсказки искомого метода, если задача диагностическая.
2. Решение: модель -> данные/единицы -> закон -> вывод -> подстановка -> физическая проверка -> ответ по каждому подпункту. Для элементарного задания можно сократить повторяющиеся шаги.
3. Подсказки: выбор модели; уравнение/схема; ключевой промежуточный шаг. Полный ответ отдельно.
4. Уровни: 1 прямая подстановка; 2 несколько вычислений; 3 выбор модели и сочетание законов; 4 многоэтапное движение/системы/ограничения; 5 исследование/оптимизация/доказательство/численные методы.
5. Типы: concept, calculation, graph_reading, graph_construction, inverse, error_analysis, modeling, research.
6. Коды компетенций: KIN-01 SI; KIN-02 система отсчёта; KIN-03 путь/перемещение; KIN-04 векторы/проекции; KIN-05 графики; KIN-06 уравнения движения; KIN-07 относительное движение; KIN-08 многоэтапное движение; KIN-09 производные; KIN-10 интегралы; KIN-11 допустимость; KIN-12 размерности/проверка. Предметные подкоды добавлять контролируемо.
7. Поля для будущей миграции: task_type, primary_competency, competency_ids, prerequisites, solution_steps, hints, answer_spec, rubric, pedagogical_role, review_status. Сохранять текущие поля для обратной совместимости.
8. Учебная последовательность: диагностический вопрос -> разобранный пример -> аналогичная самостоятельная -> изменение одного параметра -> обратная задача -> комплексная -> рефлексия. Исходная нумерация сохраняется, учебный порядок — отдельное поле.
9. Для ЕГЭ и школьного обучения различать базовую алгебраическую модель и математическое расширение с производными, интегралами, численными методами. Точный экзаменационный маппинг в этом ревью не проверялся.
10. Для добавочных упражнений независимые идентификаторы MB; источник/редакторская адаптация отдельно. Репозиторий публичный: проверить права на распространение оригинальных условий.

## План
- Этап A: P0, перепроверка всех спорных графиков и физических условий, формальная приемка; глава 1.
- Этап B: единый шаблон решения и подсказок, переразметка сложности и компетенций, полный ответ по каждому вопросу.
- Этап C: добавить авторские концептуальные, графические, обратные и комплексные задачи в слабые главы; предварительный ориентир 3–5 дополнительных сложных задач на главу, уточнить после диагностики.
- Этап D: автоматические проверки схемы JSON, ссылок, формул/решений на эталонах, визуальные тесты браузера, учебная апробация. Синхронизация встроенного JSON в HTML после каждой правки.
- Критерии готовности: нет блокирующих дефектов; каждый обязательный график читаем; ответы полны; отмечены все адаптации/спорные задачи; пререквизиты и сложность единообразны; проверен фактический пользовательский сценарий.
