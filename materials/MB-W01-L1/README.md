## Пособие

- 121 физическая страница A4, 20/20/20/22 мм, DejaVu Serif 11 pt, pdfLaTeX, русский язык.
- 13 разделов теории, 39 мини-упражнений с ответами, 30 разобранных примеров и 90 самостоятельных задач A/B/C/D = 30/30/20/10.
- К каждой самостоятельной задаче 2 последовательные подсказки, полное решение и строка в ответном ключе.
- 11 эвристик, 13 авторских математических TikZ-иллюстраций, 9 страниц алгоритмических блок-схем, 59 дополнительных вопросов с ответами.

## Исходники и сборка

Все файлы включены в этот каталог: `book.tex` (автономный), `build_book.py`, `content/book.json`, `figures/*.tikz`, `apply_style33.py`, `update_handwrite.py`, `qa/check_book.py`, `qa/check_style33.py`.

В репозитории/CI:
```sh
cd materials/MB-W01-L1
python build_book.py --compile
python qa/check_book.py
python qa/check_style33.py
```

Зависимости: Python 3.11+, PyMuPDF, pdfLaTeX и стандартные TeX Live пакеты с поддержкой русского языка, `pdffonts` из poppler-utils.

Результаты воспроизводимого независимого прогона: [GitHub Actions #45392702179](https://github.com/ArtemLevin/math-blast/actions/runs/45392702179), **28/28** структурных, **32/32** стилевых, 121/121 страниц A4 и посимвольное совпадение математического текста с нормализацией только пробелов.

## Контроль и последующие изменения

- Полный независимый протокол M1–M12: `review-manual.md`, итог `APPROVED`.
- Реестр проверки 30 примеров, 90 задач и 39 мини-упражнений: `qa/math-review-ledger.json`.
- Источники в книге: библиография для дополнительного чтения; задачи и иллюстрации написаны специально для Math Blast.
- **Любое исправление учебного содержания, формул и ответов требует повторного ревью PDF и синхронного изменения веб-книги**.
- Веб-книга `books/MB-W01-L1/index.html` проходит отдельную процедуру W1–W10; статус её публикации фиксируется отдельно от утверждения PDF.
