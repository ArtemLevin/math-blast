# MB-W01-L1 — первый учебник Math Blast

**Тема:** Что такое математическое доказательство? Истинность утверждений  
**План:** модуль 1 / неделя 1 / занятие 1 из 144  
**Редакция:** DRAFT, ожидает независимого ревью

В ходе подготовки собран полный кандидат PDF: 110 фактических страниц A4, 30 разобранных примеров, 90 самостоятельных задач (A30 / B30 / C20 / D10), 180 подсказок, 90 решений, 90 строк ответов, 59 дополнительных вопросов с ответами, 13 авторских векторных иллюстраций, 11 эвристик.

Собранный PDF, XeLaTeX-исходник, канонический структурированный контент `content/book.json`, файлы TikZ, генератор, отчёт QA и тестовый скрипт переданы отдельно в архиве **MathBlast_MB-W01-L1_complete_DRAFT.zip** в ChatGPT. Копирование этого архива в GitHub из коннектора требует отдельного переноса двоичных/крупных файлов.

**Этот PR — учётная карточка кандидатного издания и отчёт о проверках.** Пока PDF, редактируемые источники и тесты не попали в ветку, PR остаётся DRAFT; переход к APPROVED или веб-публикации запрещён.

## Необходимое для закрытия PR
1. Перенести в `materials/MB-W01-L1/` файлы `book.pdf`, `book.tex`, `build_book.py`, `content/book.json`, `figures/*.tikz`, `qa/check_book.py`.
2. Выполнить воспроизводимую сборку и сверить SHA PDF и JSON с манифестом.
3. Провести независимое ревью по `02_REVIEW_MANUAL.md`, устранить замечания, зарегистрировать итоговый статус.
4. После утверждения создать веб-эквивалент из той же редакции контента.

**Важно:** существующий `index.html` и пользовательский прогресс `olympiad_math_plan_v2` в этом PR не изменены.
